# 公海

**一艘渔船，三十三个人，一片没有法庭的海。**

一部跑在浏览器里的中文文字游戏。纯前端、单机、**不联网**。

取材自 2011 年「鲁荣渔 2682 号」事件。船名、公司、人物都是真的，主角是虚构的。

十种结局，没有一种是「赢」。

---

## 它是什么

2010 年 12 月 27 日，你和三十二个人一起上了一条去南太平洋钓鱿鱼的船。合同上写保底四万五。你在船上待了八个多月，回来的时候，船上只剩下十一个人。

这不是一个逃出生天的故事。

你操作一根仪表盘和三本账，在**每天夜里有人来找你**的时候做选择。每一次选择都在推动体力、处境、关系，以及一个**不可逆**的东西——你的手。

- **十种结局**，包括两种中途出局、三种把命交给了海，和四种活到岸上的判决。活到岸上的那些，区别只在于你手上到底有几条命。
- **一局 20 多次选择，8–12 分钟。**主线按真实时间线推进，中间穿插随机的夜航片段。一个节点最多四行字。
- **没有正确答案。**拒绝的人死在太平洋；加入的人活到岸上，然后进监狱。游戏只让你选，你愿意付哪一种代价。
- **藏了最难的一条路**：你救过一个人。走到它需要运气，也需要你从头到尾都没选错。
- **有关键节点配图**，8 张。网址后面加 `?slots=1` 可以看到所有还没配图的位置。

## 怎么开始

**在线玩**：<https://heipig.github.io/gonghai/>

**离线玩**：把整个文件夹拷到任何地方，双击 `index.html`。不用装任何东西，不用联网，不用服务器。

> 这个游戏不发起任何外部请求：没有 CDN、没有远程字体、没有统计脚本。海浪声、心跳、落水声全部由代码在浏览器里**现场合成**——连一个音频文件都没有。你可以拔掉网线玩。

## 三步上手

1. 在标题页填一个名字（默认为「阿生」），点 **`开 始 航 行`**。
2. 读完每一段文字，点正文区域可以跳过逐字动画。下面会出现选项，点一个，或者按键盘 `1`–`9`。
3. 做完选择之后，屏幕下方会闪一行小字告诉你数值变了什么（`体力 -8 · 处境 +10 · 刘贵夺 +2`）。看它，它会告诉你你在玩什么。

右上角三个按钮：**`史实`**（这件事的真相）、**`日志`**（你的账和做过的事）、**`设置`**。

## 结果怎么看

顶部三根仪表：

| | 是什么 | 归零会怎样 |
|---|---|---|
| **体力** | 卸货、缺觉、伤口都在扣它 | 你倒在甲板上 |
| **处境** | 这条船上还有没有人拿你当自己人 | 你被叫出去 |
| **手** | 干净，或者沾血几次 | **这条不可逆。**判决的时候按它结账 |

「处境」是**双向**的：太低你会被当成外人处理掉；但一味顺着走，你会发现自己已经站在某个位置上，而那个位置是要还的。

点 **`日志`** 可以随时看到六个关键人物**各自**对你的态度（敌对／冷淡／一般／信你／交心），以及你做过的每一个选择。他们之间经常互相冲突——你不可能都讨好。

## 危险的部分

- **「沾血」是不可逆的。** 你一旦动过手，有些门就永久关上了：再也不能走干净的路线，某些场景不会再对你开放。反过来也一样——手上干净的人看到的是一条不同的船。
- **做了选择就写进日志。** 靠岸之后，法庭上会把这份日志一条一条摆出来。你走不掉。
- **条件不满足的选项会灰掉，并写出原因**（比如「你根本不知道那个阀在哪儿」）。这是故意的——你要能看见自己关掉了哪扇门。
- **有几个选项是完全隐藏的。** 你不够格的时候连看都看不到。重玩才会发现。

## 常见问题

**必须联网吗？**
不必。也不联网。在线版和离线版是同一份代码。

**有存档吗？**
自动存在你自己的浏览器里（localStorage）。标题页会出现 `继续上次航行`。关掉网页再回来还能接着玩。通关记录（收集了几种结局）也存着。

**卡住了怎么办？**
不会卡住。每一段都有路可走。如果某个选项是灰的，那是条件不满足，换一个。

**我死了很多次。**
前 171 天你是死不了的（那一段是铺垫）。从劫船那天（2011 年 6 月 16 日）起才会真的丢命。体力归零主要是因为你一路都在硬扛，处境归零主要是因为你一路都在拒绝——两条路都会死人，这就是这个游戏想说的东西。

**里面的话是真的吗？**
加了引号的，尽可能取自公开报道里的原话（庭审记录、记者采访）。详见游戏里的 **`史实`** 页，那里写清楚了我虚构了什么。

**手机上能玩吗？**
能，界面是响应式的。

## 运行要求

任何支持 Web Audio 的现代浏览器（Chrome / Edge / Firefox / Safari 近几年的版本都行）。没有其他要求——不需要安装、不需要构建、不需要网络。

## 已知不足

- 只有中文。
- 夜航片段是随机抽的，所以同一个故事点不同两局看到插曲的顺序会不一样。这是设计（它让每周目都不同），但也意味着某些人物线索你可能一整局都碰不到。
- 结局收集进度存在浏览器里，换设备或清缓存就没了。
- 音频在用户第一次点击之前不会响（浏览器的规矩，不是 bug）。
- 配图是 AI 生成的示意图，不是历史照片，也不作血腥描绘。

## 关于这个故事

**主角是虚构的。**船上没有这样一个人。「生物工程毕业、投了三百多份简历」这个设定是为了让今天的读者有一个立足点。

**其余是真的。**船名「鲁荣渔 2682 号」、荣成市鑫发水产公司、刘贵夺、李承权、夏琦勇、马玉超、姜晓龙、包德吉日胡、王延龙、温斗这些名字，都来自公开的法庭审理与新闻报道。真实的那条船上有一个刚毕业的大学生叫马玉超——他是全案唯一没有沾血的人，自己跳了海。他在游戏里也在，是真实的那一个。

2011 年，33 人出海，22 人死亡或失踪，11 人生还——**而这 11 人全部获刑**。

游戏里的 **`史实`** 页面写了完整的事实和取材来源。玩完请看一眼。
